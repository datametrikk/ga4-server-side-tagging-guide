# Enterprise GA4 & Server-Side Measurement Protocol Guide

This open-source implementation guide covers server-side event dispatching, first-party cookie persistence, and programmatic attribution setup for modern marketing stacks.

## 1. Measurement Protocol Architecture
Server-side event collection routes conversion payloads through a first-party tagging cluster before dispatching to Google Analytics 4 (GA4) and Meta Conversions API (CAPI), preventing client-side ad-blocker signal loss.
